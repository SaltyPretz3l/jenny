# Jenny tutorials

Practical walkthroughs for common first-time tasks. Each tutorial assumes Jenny is installed (see [README.md](../../README.md) for prerequisites) and walks through one end-to-end flow.

| Tutorial | Time | What you'll do |
|---|---|---|
| [01 — First chat with Jenny](01-first-chat.md) | ~10 min | Launch the app, complete first-launch setup, send your first message, understand what's happening. |
| [02 — Adding an MCP server](02-adding-mcp-server.md) | ~10 min | Configure an MCP server through `mcp-servers.json`, see it appear in Settings → Skills, watch its tools become available. |
| [03 — Personality customization](03-personality-customization.md) | ~5 min | Change Jenny's name, switch between built-in personality profiles, write a free-form personality note. |

If you need broader reference material, see:

- [README.md](../../README.md) — install, prerequisites, common commands.
- docs/INDEX.md — central docs discovery.
- [docs/TOOLS.md](../TOOLS.md) — what each tool does and when Jenny will call it.
